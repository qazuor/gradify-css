# Gradify CSS

Generador de degradados CSS lineales y radiales con previsualización en vivo, ideal para backgrounds modernos y consistentes.

- Features
  - Soporte para degradados lineales y radiales
  - Paleta de colores con múltiples stops y randomizer
  - Export en formato CSS, Tailwind y variables CSS

- Stack
  - React
  - TypeScript
  - Tailwind CSS
